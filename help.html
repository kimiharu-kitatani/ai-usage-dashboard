計算の見方

大きな数字は「今日の枠の残量%」です。推測値は入れず、取得できた値だけを使います。不明なときは「不明」と表示します。

週の始まりと「今日」の区切り

  • 週の開始 = 週間枠の resets_at − 7日（サービスごとに違う）。
  • 日境界 = 週開始から 24時間ごと（カレンダー日付ではなく、リセット時刻基準）。
  • 日番号 d = floor(経過時間 / 24h) + 1（1〜7）。

日始まりの使用率の記録

コレクターが data/usage.json の day_track に保存します。

  • week_start … その週の開始時刻
  • day_start_used[d] … その日の境界直後の「週間使用%」
  • 新しい日番号を初めて見たとき、境界直前に記録していた週間%をそのまま採用（使用量は取得トリガーの利用なしには増えないため正確）。
  • その週に境界前のスナップショットが無い場合、1日目は 0。それ以外は不明扱い。

今日の枠と残量%

  • todayQuota = d × 100/7 − dayStartUsed（週全体に対する%、今日使える分）
  • todayUsed = weeklyUsed − dayStartUsed
  • remainPct = floor( max(0, (todayQuota − todayUsed) / todayQuota × 100) )
  • todayQuota ≤ 0 のときは赤で「今日の枠なし」

サブテキスト例: 「今日使える分 23.6% のうち 4% 使用（週の枠全体に対する%）」

具体例

週開始: 月曜 09:00、いま: 火曜 19:23 → d = 2
dayStartUsed = 5%、週間使用 = 9%
todayQuota = 2×100/7 − 5 ≈ 23.6%
todayUsed = 9 − 5 = 4%
remainPct = floor((23.6−4)/23.6×100) = 83%

5時間枠への自動切替

5時間の残り%（週%と同じ単位で比較）が、今日の残り枠 todayQuota − todayUsed より小さいとき、大きな数字は5時間残量%になり、ラベルは「5時間枠で制限中」。そうでなければ「今日の分で制限中」。

ウィジェットの小さなタグ: 日 = 今日ペース、5h = 5時間枠。

色（残量の閾値・電池と同じ）

  • 緑 … 残量 ≥ 50%
  • 黄 … 20%〜50%
  • 赤 … 残量 < 20%、または今日の枠なし

週間バーの線

  • 細い目盛り … 週の 1/7〜6/7（日境界の目安）
  • 太い白線 … 今日までの目標ペース d × 100/7

不明

週間値・日始まり記録・5時間値が揃わないときは推測せず「不明」と表示します。
